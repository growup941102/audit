# 需求文档

## 背景
数据调度列表页已有“重新执行、继续执行、暂停、停止、批量删除、删除、刷新”按钮，但未接入真实后端动作接口。

## 目标
基于现有数据调度页面，新增可落库的运维动作接口并接入前端：
1. 重新执行（批量）
2. 继续执行（批量）
3. 暂停（批量）
4. 停止（批量）
5. 批量删除
6. 单条删除
7. 刷新（调度视角）

## 约束
- 使用参数化 SQL，禁止字符串拼接写库。
- 默认以 taskId（对应 queue.resource_id）为主键动作。
- 动作支持幂等：重复调用不应报错。
- 仅作用于 `c_r_cm_task_item_queue` 的项目级任务（`file_id LIKE 'PROJECT:%'`）。
