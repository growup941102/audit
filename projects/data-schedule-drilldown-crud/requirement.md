# 需求文档

## 1. 背景
- 当前 `ScheduleDetailView` 页面中，字段编辑与下钻行操作按钮大量不可点击。
- 后端下钻行接口虽存在 `create/update/delete` 路由，但动作开关常量为 `false`，且逻辑未真实落库。

## 2. 目标
- 让 `ScheduleDetailView` 的 CRUD 相关按钮在满足条件时可点击。
- 打通字段编辑与下钻行新增/编辑/删除的真实数据库写入链路。
- 严格按 TDD 实施，并遵循 `safe-sql-api-workflow`。

## 3. 范围
### 本次范围
- 字段编辑按钮可点击规则优化（含 locator 兜底）。
- 下钻 payload 的 `actions` 动态计算。
- 下钻 `create/update/delete` 改为真实 SQL 落库。
- 前端下钻行弹窗仅渲染可编辑列。

### 不在本次范围
- 不新增 Preview 功能。
- 不改动数据调度任务主列表逻辑。

## 4. 验收标准
- [ ] 字段有可定位条件时，编辑按钮可点击并可保存入库。
- [ ] 下钻弹窗中新增/编辑/删除按钮可按权限状态点击。
- [ ] 下钻行新增/编辑/删除后刷新数据可见真实变更。
- [ ] 后端测试通过，前端类型检查通过。
