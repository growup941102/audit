# MCP 选型与使用说明

## 1. 目的
这份文档用于记录当前项目优先考虑的 MCP，以及它们各自适合解决的问题。目标不是堆安装细节，而是帮助在新线程里快速判断：

- 什么时候该用哪个 MCP
- 使用前要先向用户说明什么
- 哪些场景要特别谨慎

## 2. 当前项目优先 MCP

### Playwright MCP
- 适用场景：
  - 前端页面流程验证
  - 表单、弹窗、列表、登录等交互回归
  - 复现浏览器端问题
  - 生成或辅助编写 E2E 测试思路
- 适合输入：
  - 页面地址
  - 要验证的交互步骤
  - 期望结果
- 预期输出：
  - 页面交互结果
  - 操作路径
  - 失败步骤定位
  - 必要时的测试建议
- 使用前说明：
  - 是否需要打开真实页面
  - 是否会使用登录态
  - 是否会进行提交、保存、删除等副作用操作
- 备注：
  - 更适合“真实用户流程验证”
  - 优先用于前端联调和回归验证

### Chrome DevTools MCP
- 适用场景：
  - 前端页面调试
  - 网络请求分析
  - 控制台报错排查
  - 性能问题分析
  - DOM/CSS/渲染问题定位
- 适合输入：
  - 页面地址
  - 问题现象
  - 需要重点检查的接口、控制台或性能指标
- 预期输出：
  - 控制台错误信息
  - Network 请求状态
  - 性能分析线索
  - 页面结构或样式问题定位
- 使用前说明：
  - 是否会连接本地或测试环境页面
  - 是否只读分析，还是会伴随页面交互
- 备注：
  - 更适合“前端技术排障”
  - 当问题集中在浏览器行为、请求链路、性能指标时，优先于 Playwright

### Context7
- 适用场景：
  - 查最新、版本相关的框架/API 文档
  - 生成更贴近当前版本的代码示例
  - 避免使用过时接口
- 适合输入：
  - 库名/框架名
  - 版本信息
  - 具体 API、能力或报错
- 预期输出：
  - 最新文档片段
  - 版本对应示例
  - 相关 API 使用方式
- 使用前说明：
  - 要查哪个库
  - 是否需要限定版本
  - 希望拿到的是概念说明还是代码示例
- 备注：
  - 在实现前端或后端新能力、修复框架用法问题时非常有价值
  - 适合和 `grok-search` 配合使用：一个偏“最新文档”，一个偏“联网检索和来源”

### SSH MCP Server
- 适用场景：
  - 远程服务器排查
  - 远程执行命令
  - 上传/下载文件
  - 检查部署环境、日志、配置
- 适合输入：
  - 服务器地址
  - 登录方式
  - 要执行的命令或脚本
  - 要查看的文件路径
- 预期输出：
  - 命令执行结果
  - 文件列表/文件内容
  - 远程环境诊断信息
- 使用前说明：
  - 连接的是哪台机器
  - 为什么必须远程操作
  - 是只读检查还是会改远程文件/执行写操作
- 风险等级：
  - 高
- 备注：
  - 默认视为高风险 MCP
  - 涉及生产、删除、重启、改配置、执行脚本时，必须再次明确确认

### MySQL MCP
- 适用场景：
  - 查看数据库结构
  - 查询表字段、索引、约束
  - 生成数据库概览或表文档
  - 执行 SQL 查询
- 适合输入：
  - 数据库连接目标
  - 表名
  - 查询 SQL
  - 是否只读
- 预期输出：
  - 数据库概览
  - 表结构说明
  - SQL 查询结果
  - 表文档
- 使用前说明：
  - 连接哪个数据库
  - 当前安全模式是什么
  - 是否只读
  - 是否可能写入数据
- 风险等级：
  - 中到高
- 备注：
  - 当前项目数据库是 MySQL，这个 MCP 很适合做结构理解和文档补充
  - 默认优先使用只读模式

## 3. 本项目推荐优先级

### 第一优先级
- Context7
  - 用于新代码实现前确认最新文档和 API 用法
- Playwright MCP
  - 用于联调、交互验证和回归流程
- Chrome DevTools MCP
  - 用于浏览器排障、控制台、网络和性能分析

### 第二优先级
- MySQL MCP
  - 用于理解数据结构、补后端文档、辅助联调

### 谨慎使用
- SSH MCP Server
  - 只有本地信息不足、且确实需要远程环境介入时再用

## 4. 项目内统一规则

使用任意 MCP 前，都先向用户说明：
- 为什么这次需要它
- 输入是什么
- 预期输出是什么
- 是否存在写操作、副作用或环境风险

如果能先用本地代码阅读、日志、文档、测试解决，就优先不用 MCP。

## 4.1 SQL 安全配套 Skill（推荐）

当需求涉及“补接口 + 连 SQL + 可能写库”时，建议同时使用：
- `projects/skills-mcp/safe-sql-api-workflow/SKILL.md`

该 skill 强制执行：
- 默认只读
- 写操作二次确认
- 先测试库再生产
- 事务与回滚预案
- `SELECT` 命中范围预检
- 联调前后审计记录
