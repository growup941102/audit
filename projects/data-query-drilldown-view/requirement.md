# 需求文档

## 1. 背景
- 业务背景：
  数据查询页需要支持对关键字段进行下钻查看，提升用户从“汇总列表”进入“明细内容”的效率。
- 当前现状：
  `DataQueryTable.tsx` 中会出现 `招标代理机构`、`评标专家信息`、`开标人员信息` 三列，后端已将其值处理为“查看”，但当前仅为文本不可点击。
- 相关页面/模块：
  - `frontend/src/pages/(base)/data-fetch/data-query/modules/DataQueryTable.tsx`
  - `frontend/src/pages/(base)/data-fetch/data-schedule/modules/ScheduleDetailView.tsx`

## 2. 目标
- 核心目标：
  在数据查询页将上述三列的“查看”变为可点击入口，点击后展示与 `ScheduleDetailView.tsx` 中“查看下钻内容”一致或高度一致的明细视图体验。
- 预期价值：
  - 减少用户跳转路径
  - 降低信息检索成本
  - 与现有“数据详情查看”心智保持一致

## 3. 范围
### 本次范围
- 数据查询页（DataQuery）中三列“查看”交互能力。
- 明细弹层（或等效容器）的展示能力。
- 前后端接口契约补齐（若现有接口无法直接复用）。

### 不在本次范围
- 不改 `ScheduleDetailView.tsx` 的编辑/新增/删除逻辑（该页面维持现状）。
- 不新增数据库表结构，不做迁移。
- 不扩展到除三个目标字段之外的其他字段。

## 4. 用户故事
- 作为 `数据查询用户`，我希望 `在数据查询列表直接点击“查看”并看到该项目该字段的明细内容`，从而 `快速完成核查，无需额外跳转页面`。

## 5. 功能需求
- [ ] 需求 1：在 DataQueryTable 中，当列为 `招标代理机构`、`评标专家信息`、`开标人员信息`（或对应 key）时，单元格展示为可点击“查看”按钮/链接。
- [ ] 需求 2：点击“查看”后弹出明细视图，内容结构与 `ScheduleDetailView.tsx` 中查看下钻内容保持一致（字段列、数据行、分页/滚动等）。
- [ ] 需求 3：明细加载失败时给出明确错误提示，且不影响列表主视图继续使用。
- [ ] 需求 4：当明细为空时展示空态，交互可正常关闭返回列表。
- [ ] 需求 5：仅针对这三类字段启用“查看”点击，其它字段保持原有展示。

## 6. 非功能需求
- 性能：
  点击“查看”后首屏响应建议在可接受范围内（目标 < 1.5s，受后端接口耗时影响）。
- 安全性：
  继续沿用现有鉴权，接口仅对已登录用户开放。
- 兼容性：
  保持现有桌面端表格与弹窗布局行为一致。
- 可维护性：
  优先复用现有下钻展示逻辑，避免重复实现。

## 7. 数据与接口影响
- 前端影响：
  `DataQueryTable` 需要新增点击行为；`data-query` 模块可能新增下钻弹层组件和 hooks。
- 后端影响：
  若现有 data-query 接口不足以返回明细，需要补充“按项目+字段下钻”接口。
- 数据库影响：
  无 schema 变更，仅读取现有业务表。
- 第三方/MCP 影响：
  无。

## 8. 交互与界面说明
- 可抽离的组件机会：
  下钻明细弹层可抽离为复用组件，供 DataQuery 与 DataSchedule 复用。
- 需要覆盖的状态：加载中 / 空态 / 异常 / 成功
  - 加载中：弹层内 loading
  - 空态：暂无数据
  - 异常：toast + 保留关闭能力
  - 成功：展示明细表格

## 9. 验收标准
- [ ] 在 DataQuery 列表中，三列“查看”均可点击。
- [ ] 点击后能看到对应明细内容，展示结构与 ScheduleDetailView 的查看内容一致或高度一致。
- [ ] 不影响 `ScheduleDetailView.tsx` 中编辑/新增/删除能力。
- [ ] 非目标列不出现“查看”点击行为变更。
- [ ] 异常/空态可正确反馈。

## 10. 风险与疑问
- 风险：
  - DataQuery 当前接口仅返回透视值，可能缺少下钻明细所需上下文（如 taskId 或定位键）。
  - 若直接复用 DataSchedule 下钻接口，参数模型可能不兼容。
- 疑问：
  - DataQuery 弹层是否需要提供编辑/新增/删除？当前建议默认只读查看（待你确认）。
  - 明细展示是否要求“完全等同”ScheduleDetailView，还是允许样式简化但信息一致？

## 11. 确认关卡
- 未经用户确认，不进入编码阶段。
