# 页面接口文档索引

## 1. 目的
按“前端页面”维度组织接口文档，方便联调和问题排查时快速定位。

## 2. 使用方式
1. 先按页面路由找到对应文档。
2. 再查看该页面下的接口清单、参数、返回、后端入口与库表依赖。
3. 若页面文档不存在，按既有样例补充新页面文档并更新本索引。

## 3. 页面清单

| 页面名称 | 前端路由 | 文档 |
| --- | --- | --- |
| 数据概览 | `/data-fetch/data-overview` | `page-api-data-overview.md` |
| 数据查询 | `/data-fetch/data-query` | `page-api-data-query.md` |

## 4. 文档结构规范（每个页面）
每个页面文档建议包含：
- 页面概览（路由、前端入口文件）
- 接口清单（路径、方法、鉴权、参数、返回）
- 串联链路（页面 -> hook -> api -> backend 路由 -> view -> SQL/表）
- 关键业务逻辑（状态判定/聚合/排序规则）
- 常见失败与排查入口
- 接口编写示例（可复用模板）
